# SharpLens AI

Настольное приложение для Windows 10 (2004+) / Windows 11, C# / .NET 8 / WPF.

## Запуск

Нужны .NET 8 SDK для сборки и языковые компоненты Windows OCR для русского и английского языков. В параметрах Windows установите соответствующие языки и компонент распознавания текста. При отсутствии компонента приложение сообщит, какой язык недоступен.

```powershell
dotnet restore SharpLensAI.csproj
dotnet build SharpLensAI.csproj -c Release
dotnet run --project SharpLensAI.csproj
```

`global.json` фиксирует ветку SDK 8.0.4xx. Готовый EXE после сборки: `bin/Release/net8.0-windows10.0.19041.0/SharpLensAI.exe`. На другом компьютере требуется .NET 8 Desktop Runtime.

## Работа

1. Нажмите «Захватить область» или Ctrl+Shift+X. Сочетание можно изменить в настройках, нажав новое сочетание в поле. Если оно занято, настройки не сохранятся и прежнее сочетание восстановится.
2. Выделите прямоугольник и отпустите левую кнопку мыши — захват и OCR начнутся сразу. Esc или правая кнопка отменяют выделение. Слишком маленькая область не захватывается: выделите её заново.
3. Проверьте распознанный текст слева. Он редактируется; можно также вставить текст вручную. OCR не гарантирует точность символов и отступов кода. Автоматический режим сравнивает русское и английское распознавание по строкам; смешанные языки внутри одной строки могут требовать исправления.
4. Выберите один из пяти режимов и нажмите «Обработать текст». Отправляются только текущий текст и инструкция. Снимок и история в API не отправляются.
5. Ответ отображается с заголовками, жирным текстом, списками, inline-кодом и блоками кода. «Скопировать ответ» копирует исходный Markdown. Автокопирование по умолчанию выключено.
6. Можно выбрать другой режим и повторить запрос без захвата. «Отменить» прерывает ожидание; провайдер мог уже начать обработку запроса.
7. «История» показывает до 300 последних запросов; «Открыть запрос» восстанавливает текст, инструкцию и ответ. Сохранение истории отключается в настройках.

## Яндекс

В настройках выберите «Яндекс · YandexGPT» и укажите:

- API-ключ сервисного аккаунта с ролью `ai.languageModels.user` и областью ключа `yc.ai.languageModels.execute` (или `yc.ai.foundationModels.execute`);
- ID каталога Yandex Cloud (Folder ID);
- модель, например `yandexgpt/latest`, либо полный URI `gpt://<folder-id>/yandexgpt/latest`.

Вместо API-ключа можно ввести IAM-токен и включить соответствующий переключатель. IAM-токен имеет срок действия; после истечения его необходимо заменить. Доступ к сервису и оплата настраиваются в аккаунте Яндекса, приложение не регистрирует аккаунт и не создаёт ключи автоматически.

Используется синхронный Foundation Models API с отключённым логированием данных через `x-data-logging-enabled: false`.

Официальные документы:
- https://aistudio.yandex.ru/en/docs/ai-studio/text-generation/api-ref/TextGeneration/completion
- https://aistudio.yandex.ru/en/docs/ai-studio/operations/generation/async-request
- https://github.com/yandex-cloud/docs/blob/master/en/iam/concepts/authorization/api-key.md

## Локальная или альтернативная модель

Выберите «Совместимый API / локальная модель». Укажите полный URL Chat Completions, например `http://localhost:11434/v1/chat/completions`, и точное имя установленной модели. Сервер и модель нужно запустить отдельно. Для localhost ключ необязателен. Внешние адреса должны использовать HTTPS. При переключении провайдера поле ключа очищается, чтобы случайно не отправить чужому провайдеру прежний ключ. Произвольные нестандартные API подключаются реализацией `IAiProvider`.

### Модели Qwen на устройстве

В настройках нажмите «Установить локальный ИИ…». В каталоге доступны Qwen3 0.6B (0,64 ГБ), Qwen3 1.7B (1,83 ГБ) и Qwen3 4B (2,50 ГБ). При первой установке приложение также скачает CPU-версию llama.cpp для Windows x64. После загрузки выберите модель в списке ИИ-провайдеров и сохраните настройки. Для обработки текста интернет и API-ключ не требуются.

Модели скачиваются по запросу в `%LOCALAPPDATA%\SharpLensAI\LocalAI`. Кнопка «Открыть папку» в каталоге позволяет найти и вручную удалить нужную подпапку с моделью. При возврате в настройки список обновится.

## Данные и безопасность

Настройки и история находятся в `%LOCALAPPDATA%/SharpLensAI/`. Ключ защищён Windows DPAPI и доступен только текущему пользователю Windows. Настоящие ключи не должны попадать в исходники. Старый открытый `CustomApiKey` в пользовательском файле настроек автоматически заменяется зашифрованным значением. Старые файлы рядом с EXE не импортируются: при необходимости перенесите ключ через интерфейс, удалите старую копию вручную. Если ключ ранее публиковался, его следует отозвать у провайдера.

История сохраняется локально в JSON **без шифрования**: она может содержать конфиденциальные тексты. Её можно отключить и очистить. Запись файлов атомарная; повреждённая история не перезаписывается новым запросом. Снимки существуют только в памяти. Рендерер Markdown не загружает внешние изображения и не исполняет HTML.

## Структура

- `MainWindow` — основной сценарий, состояния выполнения и отмена.
- `SnippingWindow`, `ScreenCapture` — снимок виртуального рабочего стола, подтверждение и перевод координат.
- `OcrService` — локальный Windows OCR, выбор языка, восстановление строк и приблизительных отступов.
- `IAiProvider`, `YandexProvider`, `OpenAiProvider`, `GigaChatProvider`, `CompatibleProvider`, `LlmService` — контракты API, сетевые запросы и обработка ошибок.
- `SettingsManager`, `SecretProtection` — настройки и DPAPI.
- `HistoryService`, `HistoryWindow` — хранение и просмотр истории.
- `MarkdownRenderer`, `PromptCatalog` — безопасное отображение и инструкции.

## Проверки

```powershell
dotnet run --project Tests/SharpLensAI.Tests.csproj
```

Тестовый runner без дополнительных тестовых пакетов возвращает ненулевой код при ошибке. Сетевые тесты используют подставной HTTP-обработчик, ключи и реальные запросы не нужны. OCR проверяется настоящим Windows OCR на сгенерированном изображении. История проверяется во временном файле, пользовательские данные не изменяются.

Ручная приёмка: захват кнопкой и горячей клавишей из другого приложения; завершение выделения отпусканием мыши и отмена через Esc; разные мониторы и масштабы DPI; пять режимов с реальным API; отмена; копирование; смена занятой горячей клавиши; перезапуск и открытие истории. Реальные облачные ответы требуют вашего действующего ключа.

### Изменение сочетания клавиш

Откройте «Настройки» и нажмите поле сочетания: оно подсветится, появится «Ожидаю нажатия…». Нажмите модификатор (Ctrl, Alt, Shift или Win) вместе с буквой, цифрой или F1–F11. «Сочетание принято» означает, что ввод получен; примените его кнопкой «Сохранить». Кнопка «По умолчанию» выбирает Ctrl+Shift+X и включает горячую клавишу; затем также нажмите «Сохранить». Пока настройки открыты, захват глобальной клавишей приостановлен, чтобы не мешать её вводу. При отмене вернётся прежнее сочетание. Не запускайте одновременно старую и новую копии приложения: одна из них может занять комбинацию.


## OpenAI (ChatGPT)

Выберите «OpenAI · ChatGPT», введите API-ключ из https://platform.openai.com/api-keys и имя модели, доступной вашему аккаунту. При переключении предлагается `gpt-4.1-mini`; имя можно изменить. Используется Responses API, `store=false`, передаются только текущий текст и инструкция. Поля Folder ID, IAM, scope и адрес совместимого API скрыты. При незавершённом ответе приложение предложит увеличить лимит токенов или сократить текст.

Документация: https://developers.openai.com/api/reference/resources/responses/methods/create

## GigaChat

Выберите «Сбер · GigaChat». В поле ключа вставьте готовый **ключ авторизации** из кабинета GigaChat API (без слова `Basic`), а не Client ID и не временный access token. Выберите тип доступа: `GIGACHAT_API_PERS` для физического лица, `GIGACHAT_API_B2B` для бизнес-пакетов или `GIGACHAT_API_CORP` для бизнес-доступа pay-as-you-go. Модель по умолчанию — `GigaChat`; можно указать другую доступную модель.

Перед каждой обработкой приложение получает новый временный токен через OAuth и затем использует его для запроса текста. Токен не сохраняется на диск. Ключ защищается Windows DPAPI, как и у остальных провайдеров. Проверка сертификатов HTTPS включена; если Windows не доверяет сертификату сервиса, используйте официальную инструкцию провайдера, а не отключение проверки TLS.

Документация: https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api

Настройки отображаются по выбранному провайдеру, а не по содержимому ключа: для Яндекса остаются Folder ID и IAM, для GigaChat — scope, для совместимого API — URL. При смене провайдера поле ключа очищается и подставляется пример модели, чтобы прежний ключ случайно не отправился другому сервису.

### Ошибка OpenAI HTTP 429

Приложение различает конкретный код ограничения: недостаток квоты, исчерпанный баланс, лимит расходов проекта/организации и временную частоту запросов. Для проверки аккаунта в настройках OpenAI добавлены кнопки «Баланс API» и «Лимиты API». Они открывают OpenAI Platform; приложение не меняет баланс и лимиты автоматически. При временном ограничении выводится срок Retry-After, если его вернул сервер. При неизвестном коде причина не предполагается. Ключ, исходный текст и необработанное сообщение сервера не выводятся.

Справка: https://developers.openai.com/api/docs/guides/error-codes

## Gemini

В «Настройках» выберите «Google · Gemini», введите ключ из https://aistudio.google.com/apikey и имя доступной модели. При переключении подставляется `gemini-3.5-flash-lite`; можно указать другой ID (также принимается префикс `models/`). Приложение вызывает generateContent, передаёт ключ в заголовке x-goog-api-key, не добавляет его в URL. Инструкция и пользовательский текст отправляются раздельно. Блокировка, пустой ответ, исчерпанная квота и достижение лимита ответа показываются как понятные ошибки. Квоты и доступность моделей зависят от проекта Google.

Документация: https://ai.google.dev/api/generate-content
Каталог моделей: https://ai.google.dev/gemini-api/docs/models

## OpenRouter

Выберите «OpenRouter», введите его API-ключ из https://openrouter.ai/settings/keys и полный ID модели из https://openrouter.ai/models (пример: `openai/gpt-4.1-mini`). Ключ исходного поставщика модели в этом режиме не используется. URL задан приложением автоматически. Поля Яндекса, GigaChat и OpenAI скрыты. Доступ и стоимость зависят от выбранной модели и аккаунта OpenRouter; никаких обещаний бесплатной квоты приложение не делает.

Ошибка HTTP 402 сообщает об ограничении бюджета/баланса, а не предлагает бесконечно повторять запрос. Ошибка модели внутри HTTP 200 также обрабатывается. Ключ шифруется Windows DPAPI, как и у остальных провайдеров.

Документация: https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion
Ошибки: https://openrouter.ai/docs/api_reference/errors-and-debugging
